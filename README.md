## Brick law

One brick requires a deliberate day closeout, all six standards complete, and integrity kept. A missed day can break the active streak but never erases previously earned bricks.

The six standards are Prayer / Study, Hydration + Creatine, Rehab / PT, Hevy / Training Plan, Presentation / Work Readiness, and Attention Controlled. GREEN / YELLOW / RED readiness changes the correct training dose; it does not automatically invalidate a day.
